# BLACKROOM Alpha

BLACKROOM is a cultural intelligence platform designed to explain why trends emerge by tracing signals through contradictions, narratives, ideologies, opportunities, and client applications.

## Alpha Scope

This repository contains the first buildable alpha scaffold:

- Next.js + TypeScript + Tailwind frontend
- FastAPI backend
- PostgreSQL schema
- Seed data for BLACKROOM signal ledger, contradiction library, narrative library, and ideology library
- Signal scoring framework
- Manual
